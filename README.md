# 星迹 · 学习规划与心态助手

星迹帮助学习者把目标拆成可执行的小步骤，并提供课程表、任务、专注、复盘和 AI 助手。

线上体验：https://heart-plan-6yw6bd0h6pw.qoder.zone/

## 本地运行

安装 Node.js 后，在项目目录运行：

```sh
node studyhack-web/serve.mjs
```

根据终端提示访问本地页面。本地静态服务不包含线上 AI 服务，函数代码位于 `functions/`；密钥由部署环境配置，不应提交到仓库。

## 目录

- `studyhack-web/`：网页源代码。
- `dist/`：发布静态文件。
- `functions/`：服务端函数。
- `db/`：数据库结构。
