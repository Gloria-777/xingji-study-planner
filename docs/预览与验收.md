# 本地预览与验收指引

1. 安装 Node.js，在仓库根目录运行 `node studyhack-web/serve.mjs`。
2. 使用终端显示的本地地址访问网页。此方法只预览静态网页，线上 AI 等依赖服务端配置的功能不能以本地预览结果替代。
3. 使用隔离浏览器配置和测试数据检查首页、课程表、任务、计划、专注、复盘、提醒及 AI 输入状态。确认提案时先检查内容，再执行写入；测试后核对结果。
4. 检查空数据、长文本、较小屏幕和网络异常，记录设备、操作、预期结果及实际结果。未执行的情况标为待核验。
5. 学习记录以当前浏览器内的数据为准；如需迁移，先使用应用内提供的备份功能。不要把测试操作写成真实用户业务结果。
